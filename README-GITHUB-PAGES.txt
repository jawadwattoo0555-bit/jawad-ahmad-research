JAWAD AHMAD — GITHUB PAGES WEBSITE
===================================

This folder is ready for GitHub Pages.

1. Create/sign in to GitHub.
2. Create a NEW repository, for example:
   jawad-ahmad-research
3. Upload EVERYTHING inside this folder, preserving:
   index.html
   assets/images/jawad-ahmad-portrait.jpg
   assets/images/website-design-preview.png
4. Open repository Settings → Pages.
5. Under Build and deployment, choose:
   Source: Deploy from a branch
   Branch: main
   Folder: / (root)
6. Save. GitHub will provide your public website address.

IMPORTANT:
Upload the files/folders themselves, not just the ZIP file.

CUSTOM DOMAIN:
Later you can connect a domain such as jawadahmad.com through GitHub Pages settings.

GOOGLE SITES:
Google Sites does not directly publish this HTML project as a complete custom HTML site. You can use Google Sites separately, or publish this exact design through GitHub Pages.
